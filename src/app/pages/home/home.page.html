THE PROBLEM

⚫ Most frameworks ignore what happens when your agent trusts corrupted tool output
⚫ Prompt injection is an afterthought
⚫ Memory poisoning has no mitigation layer
nbagents was built after hitting all three.

CORE CAPABILITY 1

Dynamic tool orchestration with strict type-safety and instance-level isolation.

CORE CAPABILITY 2

Stateful memory management with automated cleanup and conflict resolution.

COGNITIVE FIREWALL

Primitives baked directly into the graph to filter prompts and validate tool outputs in real-time.
